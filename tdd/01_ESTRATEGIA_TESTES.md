# Estratégia de Testes

## Objetivo

Transformar requisitos em comportamentos verificáveis.

## Framework

```text
pytest
```

## Dependências

```text
pytest
pytest-cov
pytest-mock
pytest-asyncio
responses
```

## Pirâmide

```text
70% Unitários
20% Integração
10% E2E / Avaliação
```

## Padrão dos testes

```text
Arrange
Act
Assert
```

## Regra TDD

1. escrever teste;
2. confirmar falha;
3. implementar mínimo;
4. confirmar sucesso;
5. refatorar;
6. manter regressão protegida.
