# Testes End-to-End

## E2E-001
Primeira inicialização deve criar a base.

## E2E-002
Segunda inicialização sem alteração deve reutilizar a base.

## E2E-003
Alteração documental deve provocar reindexação.

## E2E-004
Pergunta conhecida deve recuperar documento esperado.

## E2E-005
Pergunta fora da base não deve gerar resposta baseada em conhecimento externo.

## E2E-006
Falha do provedor LLM deve ser exibida de forma controlada ao usuário.
